# 🎓 AI-Based Student Fatigue Monitoring and Break Reminder System

A real-time computer vision application that detects student fatigue using OpenCV and reminds users to take breaks during long study sessions.

## Features

- 👤 Face Detection
- 👀 Eye Detection
- 😴 Fatigue Detection
- 🔔 Audio Alert
- ⏱️ Study Timer
- ☕ Break Reminder
- 📝 Fatigue Event Logging

## Technologies

- Python
- OpenCV
- Haar Cascade Classifiers
- Winsound
- Threading

## Installation

```bash
git clone https://github.com/yourusername/AI-Student-Fatigue-Monitor.git

cd AI-Student-Fatigue-Monitor

pip install -r requirements.txt
```

## Run

```bash
python Fatigue_Final.py
```

## Output

- Detects face and eyes
- Monitors prolonged eye closure
- Plays an alert sound
- Displays study timer
- Reminds users to take scheduled breaks
